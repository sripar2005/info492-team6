Evaluation Lab

Class exercise · Week 5

A smaller, hands-on check run by the team in class. We took 10 of Yousuf's Demo 2 messages, agreed on one answer key, ran the agent twice, and compared it with a simple one-keyword rule. One item (D2-019) was deliberately labeled neither a clarification nor a change, to see whether the agent would stay inside its lane.

Crossed a line: 1 of the 2 failures. The agent called the "neither" item a change needing GC attention, going beyond what the message supported.

What it tells us

The agent was close but not consistent: scores moved from 8 to 10 between identical runs, and a one-keyword rule scored in between. Demo 2's 60-document runs scored 60/60, but this lab shows a single run can hide run-to-run variation, and that a third "neither" option tempts the agent to over-flag. Next steps: clearer instructions for items outside both categories, and repeated runs when we report results.

Who did what: Yousuf and Sri each built a list of right answers and agreed on the final key, and each did half of run 3. Nithika wrote up the results and helped group the failures and judge whether the agent crossed a line.
