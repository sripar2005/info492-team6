The problem

Nobody checks the handoff. The audit does, years later.

Every change on a project passes through the same chain: a question gets answered, the contractor gives notice, prices the work, and the owner approves it. Each step has contract rules. Today those rules get checked by people under deadline, or by an auditor after the money is gone. The Webster audit found three kinds of charges that a contract check could have caught at submission.

$63,080

Equipment charges

Add-ons for the contractor's own labor and equipment on change orders, questioned for missing support.

$20,770

Fee above the contract rate

Fees on change orders billed above the rate the contract set.

$45,681

Costs already covered

Change-order items the contractor's fee was already meant to pay for.

Source: Webster School Modernization and Addition audit, December 14, 2023, about 23 months after the last pay application.

How it works

Read the contract once. Check every step against it.

ClauseStream doesn't replace the project manager. It does the rule checking at the moment a document arrives, so the PM's time goes to the calls that need judgment.

01

Reads the contract

Pulls out every notice, pricing, and fee rule, each with the exact quote it came from.

02

Checks each handoff

Decides whether an answer is really a change, which notice rule applies, and when notice is due. Code counts the dates, including weekends and holidays.

03

Flags it to a person

Every flag quotes the clause behind it. The project manager decides. Nothing is approved or rejected automatically.

Where it fits

Owners already use AI on change orders. ClauseStream starts upstream.

We interviewed an owner-side project manager who already runs an AI agent on every change order. It's strong at the math. The problems it can't see start earlier.

Change-order review tools

  • Start when the priced change order arrives
  • Check cost rollups, cover sheets, and markups
  • Work after the cost is already committed

ClauseStream

  • Starts at the RFI answer, before a change order exists
  • Catches changes disguised as clarifications, and late notice
  • Checks against each project's own contract, with the clause quoted
